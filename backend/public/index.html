How to Host This Backend on Any Website / Cloud Hosting

This backend is a standalone, lightweight Node.js Express server. You can host it 100% for free or low cost on popular cloud platforms:

1. Render.com (Recommended Free)

1. Create a free account on render.com

2. Click New + → Web Service

3. Connect this repository or upload the backend/ folder

4. Set Build Command: npm install & Start Command: npm start

5. You will get a free live HTTPS URL (e.g. https://cgjobs-api.onrender.com)!

2. Railway.app

1. Open railway.app

2. Deploy from GitHub or run railway up

3. Add environment variables from .env.example

4. Click Generate Domain to get your live URL.

3. VPS (DigitalOcean / AWS / Hostinger)

1. Copy backend/ folder to your server

2. Run: npm install

3. Start with PM2: pm2 start server.js --name cgjobs-backend

4. Point Nginx reverse-proxy to port 3000.

Available REST Endpoints for Android Client

GET /api/health // Check server connection & stats
GET /api/news?category=CGPSC&limit=20 // Fetch latest jobs & affairs
GET /api/news/:id // Single job detail
GET /api/categories // Active categories
GET /api/alerts // In-app alerts list
POST /api/alerts/register-token // Register mobile FCM token
